Ortak alanlar
Entity'lerin ortak bir taban sınıfı yoktur. 24 entity'den 16'sı IMakerCheckerEntity arayüzünü (Netix.Core.Flow.StateEngine) implement eder ve üç maker-checker alanını taşır:

Alan	Tip	Kolon
StateId	int	required
StateMaker	string	nvarchar(80)
StateDate	DateTime	datetime
Kalan 8 entity — takvim ve detay tabloları, SettlementType, PaymentInstructionType, CorporateDetailType — hiçbir arayüz implement etmez.

CreatedDate, CreatedBy, ModifiedDate gibi audit alanları bu 24 entity'nin hiçbirinde yoktur. Zaman ve kullanıcı izi yalnızca StateMaker / StateDate ile sınırlıdır, o da yalnızca maker-checker akışına giren tablolarda.

StateId bir bayrak alanıdır; NetTrex.Core.Data.Enums.FlowState bayrakları çözümler. Onaylanmış ve silinmemiş kaydın karşılığı Verified bayrağının açık, Deleted bayrağının kapalı olmasıdır. Okuma metotlarının hangisinin bu filtreyi uyguladığı Data-Managerlar sayfasındadır.

StateMaker, VolatilityRate ve CorporateType tablolarında zorunludur (IsRequired()); diğer maker-checker tablolarında boş geçilebilir (IsRequired(false)). CLR tarafı her yerde string'dir (nullable değil), yani boş geçilebilen tablolarda okurken veritabanından NULL gelebilir.

ITransactionEntity
Bu paketteki hiçbir entity ITransactionEntity'yi implement etmez; yukarıdaki 24 tablonun hiçbiri işlem tablosu değildir. Arayüz, modüllerin kendi işlem tablolarına ortak bir alan kümesi vermek için sunulur.

public interface ITransactionEntity
{
    TransactionOriginType TransactionOriginType { get; set; }
    long? LinkedTransactionId { get; set; }
    string? LinkedTransactionReference { get; set; }
    string? LinkedTransactionTrader { get; set; }
    LinkedTransactionReasonType? LinkedTransactionReasonType { get; set; }
}
Alanların anlamı ve kuralları ITransactionEntity, ConfigureTransactionEntity() çağrısı, Oracle kolon adları ve dolu tablolar için geçiş script'i LinkedTransaction Alanları sayfasındadır.
